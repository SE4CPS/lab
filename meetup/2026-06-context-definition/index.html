Context Definition for Mobile Web Apps

What the model needs to know

AntRunner Meetup · Mobile App-Development
Friday, June 26, 2026 · Online

Why Context Matters

  • Prompts alone are generic
  • Context makes them specific
  • Mobile: state changes fast
  • Define it, do not improvise

What Counts as Context

  • Device: viewport, battery
  • Network: offline, slow
  • Platform: Android, iOS
  • Project: rules, patterns

Context as Files

  • base.json: shared rules
  • ctx.json per platform
  • agents.md for projects
  • Versioned like code

Context files: GitHub · builds on the April talk

Keep Context Small

  • Tokens cost attention
  • Only what the task needs
  • Prune stale rules
  • Review context like code
