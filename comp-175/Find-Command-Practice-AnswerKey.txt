COMP-175 Practice: find Command Fill-in-the-Blank -- Answer Key

1. Find all shell scripts (.sh files) in the comp175 folder.
   find ~/2026-COMP-175 -name "*.sh"
   Blank: "*.sh"  (the filename pattern -name matches against)

2. Find all files larger than 1 MB.
   find ~/2026-COMP-175 -size +1M
   Blank: -size  (the flag that filters by file size)

3. Find all directories named "lab2".
   find ~/2026-COMP-175 -type d -name "lab2"
   Blank: d  (the -type value for a directory; f would mean a plain file)

4. Find all files modified in the last 7 days.
   find ~/2026-COMP-175 -mtime -7
   Blank: -7  (mtime measures whole days; -7 means "less than 7 days ago")

5. Find all files owned by your own user account.
   find ~/2026-COMP-175 -user $(whoami)
   Blank: $(whoami)  (substitutes your own username as the -user argument)

6. Find and delete all .log files.
   find ~/2026-COMP-175 -name "*.log" -delete
   Blank: -delete  (removes every file find matches; always test without it first)

7. Find all files with permissions set to 777.
   find ~/2026-COMP-175 -perm 777
   Blank: 777  (the exact permission mode -perm checks for)

8. Find all empty files.
   find ~/2026-COMP-175 -empty
   Blank: -empty  (matches files, or directories, with zero size)

9. Find all README files, regardless of capitalization.
   find ~/2026-COMP-175 -iname "readme*"
   Blank: -iname  (the case-insensitive version of -name)

10. Find every .sh file and count its lines.
    find ~/2026-COMP-175 -name "*.sh" -exec wc -l {} \;
    Blank: -exec  (runs the given command once per matched file, {} is the match)
