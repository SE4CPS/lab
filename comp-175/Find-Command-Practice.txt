COMP-175 Practice: find Command Fill-in-the-Blank
Fill in the missing flag or argument on each blank line.

1. Find all shell scripts (.sh files) in the comp175 folder.
   find ~/2026-COMP-175 -name ____

2. Find all files larger than 1 MB.
   find ~/2026-COMP-175 ____ +1M

3. Find all directories named "lab2".
   find ~/2026-COMP-175 -type ____ -name "lab2"

4. Find all files modified in the last 7 days.
   find ~/2026-COMP-175 -mtime ____

5. Find all files owned by your own user account.
   find ~/2026-COMP-175 -user ____

6. Find and delete all .log files.
   find ~/2026-COMP-175 -name "*.log" ____

7. Find all files with permissions set to 777.
   find ~/2026-COMP-175 -perm ____

8. Find all empty files.
   find ~/2026-COMP-175 ____

9. Find all README files, regardless of capitalization.
   find ~/2026-COMP-175 ____ "readme*"

10. Find every .sh file and count its lines.
    find ~/2026-COMP-175 -name "*.sh" ____ wc -l {} \;
