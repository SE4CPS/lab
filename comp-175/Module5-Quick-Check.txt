1. How do you list every process, showing the full command each one is

   _________________________________

2. How do you find the process using the most memory, without
   scrolling through a full list?
   _________________________________
   Hint: ps takes a --sort flag; a - before the field name sorts

3. You started a job in the foreground by mistake. How do you pause it

   _________________________________
   Hint: two steps -- one keyboard shortcut, one shell builtin.

4. How do you end a process that isn't responding to a normal kill

   _________________________________

5. How do you lower a background job's CPU scheduling priority so it

   _________________________________

Answer Key (instructor copy -- remove before handing out to students)
1. ps aux
2. ps aux --sort=-%mem   (or -%mem via `ps aux --sort=-%mem | head`)
3. Ctrl+Z, then bg
4. kill -9 <PID>   (or kill -KILL <PID>)
5. nice -n <value> <command>   (or renice for an already-running job)
6. ssh-keygen -t ed25519
7. ssh-copy-id user@host
8. eval "$(ssh-agent -s)" then ssh-add ~/.ssh/id_ed25519
9. ssh -L localPort:host:remotePort user@host
10. rsync -av src/ user@host:dst/
11. pgrep -a <name>
12. top
13. jobs
14. nohup command & then disown
15. ssh-add -l
16. sudo sshd -t
17. tmux
18. ping -c 3 <host>
19. sudo -l
20. echo "IP  name" | sudo tee -a /etc/hosts
