Question 2 (10 pts)
Write the Backup Script

Write a script that backs up /srv/registrar and exits early if the folder is missing. No editor: write it with cat and a here-document.

cat > backup.sh <<'EOF'
#!/bin/bash
if [[ ! -d /srv/registrar ]]; then
  echo "Source missing, exiting"
  exit 1
fi
cp -r /srv/registrar /backups/
echo "Backed up on $(date)" >> backup.log
EOF
cat backup.sh

Explain (type it as a # comment line in the terminal): what the exit 1 line actually does if the source folder is missing.

Screenshot: the heredoc command and cat showing the saved file.
