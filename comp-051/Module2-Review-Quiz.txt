COMP-051 - Module 2 Review Quiz
Data Types, Variables & Basic I/O

Instructions: For each question, circle the letter of the correct answer,
or fill in the blank where shown.

=====================================================
TYPES & SIZES
=====================================================
1. Which type is exactly 1 byte and stores true/false?
   (a) int   (b) bool   (c) float

2. sizeof(char) returns how many bytes?
   (a) 1   (b) 2   (c) 4

3. Which native type usually uses 4 bytes?
   (a) short   (b) int   (c) char

4. Which type holds decimals with the most precision?
   (a) float   (b) double   (c) int

5. Name all 7 native types taught in Module 2: ______________

6. Which type's size can vary by OS (4 or 8 bytes)?
   (a) int   (b) long   (c) bool

=====================================================
RANGES
=====================================================
7. A signed char's typical range is about?
   (a) 0 to 255   (b) -128 to 127   (c) -32K to 32K

8. A bool can only ever hold how many values?
   (a) 1   (b) 2   (c) 256

9. int's range is about +/- 2.1 billion. True or false? ______

=====================================================
DECLARATION, ASSIGNMENT & REASSIGNMENT
=====================================================
10. int x = 5; then x = 10; what is x now? ______

11. Which symbol assigns a value to a variable?
    (a) ==   (b) =   (c) ;

12. Declaring a variable without a value is called: ______

13. Which line correctly declares an int named age?
    (a) int age;   (b) Int age;   (c) age int;

14. What ends every C++ statement?
    (a) :   (b) ;   (c) .

=====================================================
UNINITIALIZED VARIABLES
=====================================================
15. An uninitialized int holds what kind of value?
    (a) always 0   (b) garbage/unknown   (c) always -1

16. Reading an uninitialized variable is:
    (a) safe   (b) undefined behavior   (c) a syntax error

17. Best practice: always ______ a variable when declaring it.

=====================================================
BASIC I/O
=====================================================
18. Which object prints to the screen in C++?
    (a) cin   (b) cout   (c) endl

19. Which object reads keyboard input?
    (a) cin   (b) cout   (c) main

20. Which header is needed for cin/cout?
    (a) <iostream>   (b) <cmath>   (c) <string>

=====================================================

=====================================================

22. Int age = 20;                      what's wrong? ______

23. bool flag = 2;                     what's wrong? ______

8. (b) 2

10. 10

12. Declaration (without initialization)

21. A string literal ("5") can't be assigned to an int.
22. "Int" isn't a valid type -- C++ is case-sensitive; should be "int".
23. bool should only hold true/false, not the number 2.
24. Missing semicolon at the end of the line.
25. Double quotes make it a string, not a char -- needs single
    quotes: 'A'.
26. count is read/used before it was ever given a value.
27. x is declared twice in the same scope.
28. Valid, but silently truncates to 3 -- a narrowing conversion
    that loses the decimal part.
