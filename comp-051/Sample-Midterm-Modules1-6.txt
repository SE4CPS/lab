COMP-051: Sample Midterm -- Modules 1-6 (One-Page Practice Version)

Format: 6 multiple choice (10 pts each) + 1 function
implementation (40 pts) = 100 points total.

================================================================
PART 1: MULTIPLE CHOICE (10 points each)
================================================================

1. (Module 1) What is the correct order of stages that turn
C++ source code into a program that can actually run?
A. Source code, Compiler, Assembly, Assembler, Machine Code
B. Source code, Assembler, Compiler, Assembly, Machine Code
C. Machine Code, Compiler, Assembly, Assembler, Source code
D. Source code, Machine Code, Compiler, Assembler, Assembly

2. (Module 2) What value does an uninitialized LOCAL variable
hold in C++?
A. It always automatically holds the value zero
B. It holds an unpredictable garbage value left in memory
C. The program refuses to compile until it is set
D. It always holds the exact same value every run

3. (Module 3) In the expression (a && b), what does
short-circuit evaluation mean?
A. Both a and b are always evaluated fully
B. If a is false, b is never evaluated
C. If a is true, b is never evaluated
D. The compiler picks whichever is faster at runtime

4. (Module 4) What is the key difference between a while loop
and a do-while loop?
A. A do-while loop always runs its body at least once
B. A while loop always runs its body at least once
C. A do-while loop can never be nested inside another loop
D. There is no real difference between the two

5. (Module 5) For an array declared with size 6, what is its
valid range of indexes?
A. 1 through 6, inclusive
B. 0 through 6, inclusive
C. 0 through 5, inclusive
D. -1 through 4, inclusive

6. (Module 6) What is the difference between a parameter and
an argument?
A. A parameter is the placeholder in a function's definition;
   an argument is the actual value passed in at the call site
B. An argument is the placeholder; a parameter is the value
   passed in at the call site
C. A parameter can only ever be an int
D. These are two names for the exact same thing

================================================================
PART 2: FUNCTION IMPLEMENTATION (40 points)
================================================================

7. Write a complete C++ function with this exact signature:

    int maxValue(int nums[], int size)

It should return the largest value stored in the nums array.
You must use a loop to compare the values -- do not assume the
largest value's position ahead of time.
