COMP-051: Mock Midterm -- Modules 1-6

Format: 18 multiple choice + 2 function-implementation
questions, 5 points each = 100 points total.

================================================================
PART 1: MULTIPLE CHOICE (5 points each)
================================================================

Module 1 -- C++, What Is a Program?, First C++ Program

1. What is the correct order of stages that turn C++ source
code into a program that can actually run on the computer?
A. Source code, then Compiler, then Assembly, then Assembler, then Machine Code
B. Source code, then Assembler, then Compiler, then Assembly, then Machine Code
C. Machine Code, then Compiler, then Assembly, then Assembler, then Source code
D. Source code, then Machine Code, then Compiler, then Assembler, then Assembly

2. What is the relationship between the C and C++ languages?
A. C++ was built as a superset of C, adding features like classes on top
B. C was built as a superset of C++, adding features like classes on top
C. C and C++ are two completely unrelated languages with unrelated syntax
D. C++ fully replaced C, and C is no longer used in any software today

3. Why is C++ still widely used today, decades after it was created?
A. Because it is the only language that a computer's hardware can run
B. Because newer languages are not able to call any existing C code
C. Because it still powers things like OS kernels, browsers, and games
D. Because it was the very first programming language ever invented

Module 2 -- Variables and Basic I/O

4. What is the difference between declaring a variable and initializing it?
A. Declaring gives a variable a type and name; initializing gives it a value
B. Declaring gives a variable a value; initializing gives it a type and name
C. These two words are really just two different names for one same step
D. Declaring only applies to int, while initializing applies to every type

5. What value does an uninitialized LOCAL variable hold in C++?
A. It always automatically holds the value zero until it is assigned
B. It holds an unpredictable garbage value left over in that memory
C. The program refuses to compile at all until every variable is set
D. It always automatically holds the exact same value every single time

6. Why would a program use const for a value like a page limit?
A. Because const values take up much less memory than a normal variable
B. Because const stops that value from being read anywhere else at all
C. Because const documents and enforces that the value should never change
D. Because const is required before a variable can be printed with cout

Module 3 -- Branches

7. When does a switch statement work better than a long if/else chain?
A. When you are testing one variable against several exact, known values
B. When you are testing whether a number falls inside a range of values
C. When you only ever have a single condition and nothing else to check
D. Never, since if/else can always fully replace what switch can do

8. In the expression (a && b), what does short-circuit evaluation mean?
A. Both a and b are always evaluated fully, no matter what a turns out to be
B. If a is false, b is never evaluated, since the whole thing is already false
C. If a is true, b is never evaluated, since the result must already be true
D. The compiler picks whichever of a or b is faster to evaluate at runtime

9. What happens if a case in a switch statement is missing its break?
A. The program refuses to compile until every single case has a break
B. That one case simply does nothing at all, and the switch just exits
C. Execution falls through and keeps running the code in the next case too
D. The switch statement silently skips over that entire case altogether

Module 4 -- Loops

10. What is the key difference between a while loop and a do-while loop?
A. A do-while loop always runs its body at least once before checking
B. A while loop always runs its body at least once before checking
C. A do-while loop can never contain another loop nested inside it
D. There truly is no real difference between these two kinds of loops

11. Why call srand(time(0)) before using rand() in a program?
A. Because rand() will not compile at all unless srand() is called first
B. Because it seeds the sequence with the current time, so it differs each run
C. Because it guarantees rand() will never generate the same number twice
D. Because it converts rand()'s output from a whole number into a decimal

12. Inside a loop, what does the continue keyword actually do?
A. It exits the loop immediately and skips every remaining iteration
B. It skips the rest of the current iteration and moves to the next one
C. It pauses the loop until the user presses a key to keep going
D. It repeats the current iteration over again from its very beginning

Module 5 -- Arrays & Vectors

13. What is the key difference between an array and a vector in C++?
A. An array's size is fixed at declare time; a vector can grow as needed
B. A vector's size is fixed at declare time; an array can grow as needed
C. An array can only ever hold whole numbers, never any other data type
D. There truly is no real difference between an array and a vector at all

14. For an array declared with size 6, what is its valid range of indexes?
A. Its valid indexes run from 1 up through 6, inclusive on both ends
B. Its valid indexes run from 0 up through 6, inclusive on both ends
C. Its valid indexes run from 0 up through 5, inclusive on both ends
D. Its valid indexes run from -1 up through 4, inclusive on both ends

15. What happens if code reads or writes an index outside an array's bounds?
A. C++ safely and automatically resizes the array to fit that index
B. The compiler always catches this mistake and refuses to build the code
C. This is undefined behavior; it may read/corrupt unrelated memory
D. C++ automatically wraps that index back around to zero and continues

Module 6 -- User Defined Functions

16. What is the difference between a parameter and an argument?
A. A parameter is the placeholder in the function's own definition; an
   argument is the actual value passed in when that function is called
B. An argument is the placeholder in the function's own definition; a
   parameter is the actual value passed in when that function is called
C. A parameter can only ever be an int, while an argument can be any type
D. These two words are really just two different names for one same thing

17. Why does a function need a prototype if it is called before it is
defined further down in the same file?
A. Without one, the compiler has not seen that function yet at the
   call site, and building the program will fail with an error
B. A prototype is only ever needed for functions that return void
C. A prototype makes that function run faster once the program starts
D. A prototype is only required when a function takes zero parameters

18. What is the key difference between a function that returns a value
and a void function?
A. A void function can only ever be called one single time in a program
B. A function with a return type sends a value back to its caller; a
   void function performs an action but sends nothing back at all
C. A void function is the only kind that is allowed to take parameters
D. A function with a return type can never take any parameters at all

================================================================
PART 2: FUNCTION IMPLEMENTATION (5 points each)
================================================================

19. Write a complete C++ function with this exact signature:

    double average(int scores[], int size)

It should return the average of the size values stored in the
scores array. You must use a loop to add up the values before
computing the average -- do not hardcode the number of scores.

20. Write a complete C++ function with this exact signature:

    bool isPassing(int grade)

It should return true if grade is 60 or greater, and false
otherwise. You must use an if statement (or if/else) to decide
the result.
