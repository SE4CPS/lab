Notes:
8. C -- "class Dog : public Animal" uses the access specifier
   public (not a keyword like "extends") after the colon to
   inherit from the base class.
9. B -- file I/O needs #include <fstream>; ofstream opens a
   file for writing, ifstream opens one for reading. The same
   >> and << operators from cin/cout work on both.
10. B -- marking a base class function virtual lets a derived
    class override it, so calling it through a base pointer or
    reference runs the derived version (polymorphism).
