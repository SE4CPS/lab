7. maxValue(int nums[], int size) -- sample correct answer:

    int maxValue(int nums[], int size) {
      int best = nums[0];
      for (int i = 1; i < size; i++) {
        if (nums[i] > best) {
          best = nums[i];
        }
      }
      return best;
    }

Full credit needs: best initialized from a real array element
(nums[0], not 0 or INT_MIN as a guess), a loop that visits every
remaining element (1 through size - 1), a comparison that updates
best only when a larger value is found, and a return of best.

Partial credit for an off-by-one loop bound (e.g. starting at 0
and redundantly comparing nums[0] to itself -- harmless but
imprecise) or for initializing best to 0 instead of nums[0] (fails
silently whenever every value in nums is negative). No credit for
hardcoding size instead of using the parameter, or for a function
that doesn't compile (wrong signature, missing return).
